# Smart Home Mobile-Responsive UI (Python)

A simple Python web app using **Flask** and **Bootstrap 5** to render a mobile-responsive smart home dashboard.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000` in your browser.
